# Bankist App

A small banking interface built while studying modern JavaScript array methods and application logic.

## Features

- User login with generated usernames and PIN validation
- Account balance calculation
- Deposit / withdrawal transaction history
- Transfer money between demo accounts
- Loan eligibility logic
- Account closure
- Sort transactions
- Current date display
- Responsive layout improvements

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Array methods: `map`, `filter`, `reduce`, `find`, `findIndex`, `some`
- DOM manipulation and event handling

## Run locally

Place these files in the same folder:

- `index.html`
- `style.css`
- `script.js`
- `logo.png`
- `icon.png`

Then open `index.html` in a browser or serve the folder with a local development server.
